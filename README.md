# Milestone 1 profiling test package

Download the ZIP and check it against SHA256SUMS.txt. The archive includes Windows x64 capture tools, build sources, and docs/capture.md.

The experimental DLL is based on stable XXMI Libraries v1.3.3. It was cross-built with LLVM and the Windows SDK. Its exported names and ordinals match the stock DLL. Windows gameplay verification is pending.

Source and development history are on the [profiling-milestone-1 branch](https://github.com/dotnought/ZZZ_DX11_Optimizer/tree/profiling-milestone-1).
