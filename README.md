# Windows DX11 capture package

If you already sent your stock XXMI run, use **3** to install the test DLL and **7** to record one Roscaelifer run. Use the same camera and graphics settings, keep the built-in costume checks enabled, and keep personal mods off. See **START HERE.txt** inside the ZIP for the steps.

Download and extract the ZIP, then open **Start Here.exe**. Choose a recording and switch back to ZZZ. The tool starts after the game comes to the foreground and shows a short result banner after saving or if the capture fails. Return to the same menu window to choose another run. Each run includes PresentMon's log.

Vanilla capture works without XXMI. The experimental native profiler is based on XXMI Libraries v1.3.3. Read **START HERE.txt** for install, capture and rollback.
